# ResumeIQ — AI Resume Analyzer

A modern, interactive, responsive resume analyzer built with **HTML, CSS and JavaScript only**.

## Features
- Resume text input and TXT upload
- Drag-and-drop file area
- ATS-style score out of 100
- Category scores for structure, skills, impact, keywords and readability
- Skill detection
- Entry-level job-role matching
- Strengths and improvement suggestions
- Downloadable text report
- Dark/light mode
- Responsive mobile design
- No backend, API key or installation required

## How to run
1. Extract the project ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Paste a resume or upload a `.txt` resume.
4. Click **Analyze Resume**.

PDF/DOCX files can be selected for file-name preview, but browsers cannot reliably extract their text without a dedicated parser. For a complete offline analysis, paste the resume text or use a `.txt` file.

## Important
The scoring is a client-side educational/demo analyzer. It is an **AI-style simulation**, not a real commercial ATS or cloud AI model.
